# Rock, Paper, Scissors

A simple command-line Rock, Paper, Scissors game written in Python. Play as many rounds as you like against the computer and keep track of your wins, losses, and ties.

## Rules

- Rock beats scissors.
- Scissors beat paper.
- Paper beats rock.
- Matching choices result in a tie.

## Requirements

- Python 3
- No third-party packages required

## Run the game

From the project directory, run:

```bash
python3 rock_paper_scissors.py
```

Enter `rock`, `paper`, or `scissors` to play a round. Enter `q` or `quit` to finish and see your final score. Invalid choices are rejected without ending the game.
